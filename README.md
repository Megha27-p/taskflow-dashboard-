# TaskFlow Dashboard - Full Stack App
Built for TechForcZ Full Stack Intern Role

## What is this?
A Task Management + Productivity Dashboard.
Users can Login, Create Tasks, See Dashboard with Charts.

## Features
- JWT Authentication
- Create, Update, Delete Tasks
- Dashboard with Charts
- Redis Caching for Fast API
- Dockerized + GitHub Actions CI/CD
- Testing with Jest

## Tech Stack
Frontend: React, Tailwind CSS, Recharts, React Query
Backend: Node.js, Express, JWT, PostgreSQL
Tools: Docker, GitHub Actions, Jest, Git

## How to Run
npm install
npm run dev
docker-compose up --build
